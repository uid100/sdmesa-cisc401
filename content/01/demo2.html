Step 1: Install the SQL Server Extension

  1. Open Visual Studio Code.
  2. Click the Extensions icon on the left sidebar.
  3. Search for SQL Server (mssql).
  4. Click Install.

Step 2: Connect to the Database

  1. Press Ctrl+Shift+P to open the Command Palette.
  2. Type MS SQL: Connect and select it.
  3. Choose Create Connection Profile.
  4. Enter the following information:
    • Server name: 192.168.0.236
    • Authentication Type: SQL Login
    • User name: cisc401
    • Password: cisc401password
    • Database name: PatientRecordsDB
  5. Save the profile when prompted.
  6. A confirmation message should appear indicating a successful connection.

Step 3: Open a Query Window

  1. Press Ctrl+Shift+P.
  2. Select MS SQL: New Query.
  3. Verify that the status bar shows you are connected to PatientRecordsDB.

Step 4: List All Tables

Run the following query:

SELECT TABLE_SCHEMA, TABLE_NAME
FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_TYPE = 'BASE TABLE'
ORDER BY TABLE_SCHEMA, TABLE_NAME;
