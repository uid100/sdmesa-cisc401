SQL Server Database Demo Using Visual Studio Code

In this exercise, you will connect to a local SQL Server instance using Visual Studio Code, create a database, create a table, insert data, and retrieve data using SQL queries.

Step 1: Install the SQL Server Extension

  1. Open Visual Studio Code.
  2. Click the Extensions icon on the left toolbar.
  3. Search for SQL Server (mssql).
  4. Install the extension published by Microsoft.

Step 2: Create a Connection to SQL Server

  1. Press Ctrl+Shift+P (Windows) or Cmd+Shift+P (macOS).
  2. Type MS SQL: Connect and select it.
  3. Choose Create Connection Profile.
  4. Enter the following values:
    • Server: 127.0.0.1
    • Authentication Type: SQL Login (or use your instructor's preferred authentication method)
    • Database: Leave blank for now
  5. Save the connection profile.
Note: Your instructor may provide different login credentials depending on your installation.

Step 3: Open a New Query Window

  1. Open the Command Palette again.
  2. Select MS SQL: New Query.
  3. A new SQL editor window will open.

Step 4: Create a New Database

For this demo, we will create a database named MyTestDB. 


CREATE DATABASE MyTestDB;
GO

Run the query using the Run Query button or press Ctrl+Shift+E.

Step 5: Switch to the New Database


USE MyTestDB;
GO

Step 6: Create a Table

Create a simple table named colors. 


DROP TABLE IF EXISTS dbo.colors;

CREATE TABLE dbo.colors (
    id INT,
    color VARCHAR(64)
);
GO

Step 7: Insert Data into the Table


INSERT INTO colors(id, color) VALUES
    (1, 'red'),
    (2, 'orange'),
    (3, 'yellow'),
    (4, 'green'),
    (5, 'blue');
GO

Step 8: Retrieve the Data

Run a query to display all rows in the table. 


USE MyTestDB;

SELECT *
FROM colors;
GO

Expected Results

The query should return five rows: 


id   color
--------------
1    red
2    orange
3    yellow
4    green
5    blue
