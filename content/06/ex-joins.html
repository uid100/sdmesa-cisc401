Multi-Table SQL Queries

Complete the following exercises to practice writing multi-table SQL queries.

Database Setup

Campus network restrictions prevent access to the instructor-hosted database. You will create and populate the database locally using SQL Server Express, just as you did in the previous database exercise.

  1. Connect to your local SQL Server Express instance using VS Code as before.
  2. Open and execute the provided 01_CreateDatabase.sql script to create the database and tables.
  3. Open and execute the provided 02_SeedData.sql script to populate the tables with data.
  4. Verify that the database was created successfully and contains records.

Example SQL Server Express connection: 

Server=localhost\SQLEXPRESS;
Database=PatientRecordsDB;
Trusted_Connection=True;
TrustServerCertificate=True;

The exact server name may vary depending on your installation. Use the same SQL Server Express instance you used in the previous exercise.

Submission Requirements

  • Submit your queries as a single SQL script file.
  • Include your name and the date in the file header comments.
  • Include the exercise number in a comment before each query.
  • Ensure each query executes successfully against your local copy of the database.
