Hospital Staff Scheduling Database Project

You have been hired as a database analyst for a regional hospital. Your task is to design, create, populate, and query a relational database that supports hospital staff scheduling across multiple departments operating 24 hours per day.

This project simulates a realistic database development process. The work is divided into three phases and requires consistent progress throughout the project period.

Learning Objectives

  • Design a normalized relational database.
  • Create tables using SQL.
  • Define primary and foreign key relationships.
  • Populate a database with realistic sample data.
  • Write multi-table queries using INNER JOIN operations.
  • Use filtering, sorting, aggregates, grouping, and self-joins.
  • Create meaningful management reports.

Database Requirements

Required Tables

  1. Department
  2. Employee
  3. Shift
  4. Schedule

Additional tables may be added if they support your design.

Suggested Table Columns

Department

  • department_id (Primary Key)
  • department_name

Employee

  • employee_id (Primary Key)
  • first_name
  • last_name
  • job_title
  • department_id (Foreign Key)

Shift

  • shift_id (Primary Key)
  • shift_name
  • start_time
  • end_time

Schedule

  • schedule_id (Primary Key)
  • employee_id (Foreign Key)
  • shift_id (Foreign Key)
  • schedule_date

Minimum Data Requirements

  • 7 departments
  • 40 employees minimum
  • At least 10 physicians
  • At least 20 nurses
  • At least 10 additional staff members
  • 3 shifts per day
  • 7 consecutive days of scheduling data
  • At least 200 schedule assignments

The purpose of these requirements is to create enough data for meaningful reporting and query testing.

With a minimum of 40 employees and 21 possible shifts during a seven-day week (3 shifts per day × 7 days), a smaller dataset may not adequately represent hospital operations.

Requiring at least 200 schedule assignments helps ensure realistic staffing levels and meaningful query results.

Business Rules

  1. Use realistic names for employees, departments, and job titles. Avoid using generic names such as "Employee 1" or "Department A."
  2. Every employee must belong to a department.
  3. Every schedule assignment must reference an existing employee.
  4. Every schedule assignment must reference an existing department.
  5. Every schedule assignment must reference an existing shift.
  6. Each department must have multiple employees assigned throughout the week.
  7. Create at least three intentional scheduling conflicts for testing purposes.

Required Query Reports

  • The following reports (queries) are required to support the hospital's scheduling needs. Each query should be designed to provide specific insights into the scheduling data.
  • Across the six required reports, your project must demonstrate the use of at least four INNER JOIN queries, two aggregate queries using COUNT() and GROUP BY, and one self-join query. hint: Consider using a self-join to compare an employee's schedule assignments to detect conflicts.

Query 1: Department Schedule Report

Hospital department managers need to view all employees scheduled to work within a specific department during the week. This report should provide a detailed listing of assigned staff.

Required Output Fields

  • Employee ID
  • Employee Full Name
  • Job Title
  • Department Name
  • Shift Name
  • Shift Date

Technical Requirements

  • Use at least one INNER JOIN.
  • Filter results for a selected department.
  • Use meaningful column aliases.
  • Sort by Shift Date, then Employee Name.

Query 2: Employee Weekly Schedule

Employees frequently need a copy of their work schedule. Create a report that displays all scheduled assignments for a selected employee during the week.

Required Output Fields

  • Employee ID
  • Employee Full Name
  • Shift Date
  • Department Name
  • Shift Name
  • Shift Start Time
  • Shift End Time

Technical Requirements

  • Use at least one INNER JOIN.
  • Filter for a specific employee.
  • Sort chronologically by date and shift.
  • Use meaningful column aliases.

Query 3: Staffing Levels Report

Hospital administrators need to know how many employees are assigned to each department and shift in order to evaluate staffing coverage.

Required Output Fields

  • Department Name
  • Shift Name
  • Number of Employees Scheduled

Technical Requirements

  • Use one or more INNER JOIN operations.
  • Use COUNT().
  • Use GROUP BY.
  • Use meaningful aliases.
  • Sort by Department Name and Shift Name.

Query 4: Scheduling Conflict Report

Hospital managers must identify employees who have been accidentally assigned to conflicting work assignments. This report should detect potential scheduling errors.

Before executing this query, intentionally create at least three scheduling conflicts in your sample data.

Examples of Conflicts

  • An employee assigned to two departments during the same shift.
  • An employee assigned to overlapping shifts on the same day.
  • Employee 100 assigned to both Emergency and Radiology during the same shift and date.

Required Output Fields

  • Employee ID
  • Employee Full Name
  • Shift Date
  • Department 1
  • Department 2
  • Shift 1
  • Shift 2

Technical Requirements

  • Use a self-join.
  • Compare schedule records for the same employee.
  • Return at least three conflict records.
  • Use meaningful aliases.
This is expected to be the most challenging query in the project.

Query 5: Department Staffing Summary

Senior management would like a summary showing how many employees are assigned to each department. This report provides a high-level staffing overview.

Show the number of employees assigned to each department according to the Employee table.

Required Output Fields

  • Department ID
  • Department Name
  • Total Employees

Technical Requirements

  • Use one or more INNER JOIN operations.
  • Use COUNT().
  • Use GROUP BY.
  • Sort from highest to lowest employee count.
  • Use meaningful aliases.

Query 6: Employee Workload Report

Managers are concerned that some employees may be scheduled significantly more or less often than others. Create a report that summarizes employee workload across the week.

Count the number of schedule assignments worked by each employee during the seven-day period.

Required Output Fields

  • Employee ID
  • Employee Full Name
  • Job Title
  • Department Name
  • Total Scheduled Shifts

Technical Requirements

  • Use one or more INNER JOIN operations.
  • Use COUNT().
  • Use GROUP BY.
  • Sort from highest to lowest workload.
  • Use meaningful aliases.
