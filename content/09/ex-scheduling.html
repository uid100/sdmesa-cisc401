Hospital Staff Scheduling Database Project

You have been hired as a database analyst for a regional hospital. Your task is to design, create, populate, and query a relational database that supports hospital staff scheduling across multiple departments operating 24 hours per day.

This project simulates a realistic database development process. The work is divided into three phases and requires consistent progress throughout the project period.

Learning Objectives

  • Design a normalized relational database.
  • Create tables using SQL.
  • Define primary and foreign key relationships.
  • Populate a database with realistic sample data.
  • Write multi-table queries using INNER JOIN operations.
  • Use filtering, sorting, aggregates, grouping, and self-joins.
  • Create meaningful management reports.

Database Requirements

Required Tables

  1. Department
  2. Employee
  3. Shift
  4. Schedule

Additional tables may be added if they support your design.

Minimum Data Requirements

  • 7 departments
  • 40 employees minimum
  • At least 10 physicians
  • At least 20 nurses
  • At least 10 additional staff members
  • 3 shifts per day
  • 7 consecutive days of scheduling data
  • At least 200 schedule assignments

The purpose of these requirements is to create enough data for meaningful reporting and query testing. With a minimum of 40 employees and 21 possible shifts during a seven-day week (3 shifts per day × 7 days), a small dataset may not adequately represent hospital operations. Requiring at least 200 schedule assignments helps ensure realistic staffing levels and meaningful query results.

Business Rules

  1. Every employee must belong to a department.
  2. Every schedule assignment must reference an existing employee.
  3. Every schedule assignment must reference an existing department.
  4. Every schedule assignment must reference an existing shift.
  5. Each department must have multiple employees assigned throughout the week.
  6. Create at least three intentional scheduling conflicts for testing purposes.

Required Query Reports

Query 1: Department Schedule Report

Display all employees scheduled within a selected department.

Required Output

  • Employee Name
  • Job Title
  • Department Name
  • Shift Name
  • Shift Date

Technical Requirements

  • Use at least one INNER JOIN.
  • Sort by date and employee name.
  • Use meaningful column aliases.

Query 2: Employee Weekly Schedule

Display the complete weekly schedule for a selected employee.

  • Use at least one INNER JOIN.
  • Filter for a specific employee.
  • Sort by date.

Query 3: Staffing Levels Report

Display the number of employees assigned to each department and shift.

  • Use one or more INNER JOIN operations.
  • Use COUNT().
  • Use GROUP BY.

Query 4: Scheduling Conflict Report

Identify employees with overlapping or conflicting assignments.

  • Create at least three intentional conflicts.
  • Use a self-join.
  • Return at least three conflict records.
This is expected to be the most challenging query in the project.

Query 5: Department Staffing Summary

Display the total number of employees assigned to each department.

  • Use INNER JOIN operations.
  • Use COUNT().
  • Use GROUP BY.

Query 6: Employee Workload Report

Display the number of scheduled shifts worked by each employee during the week.

  • Use INNER JOIN operations.
  • Use COUNT().
  • Use GROUP BY.
