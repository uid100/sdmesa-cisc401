Database Basics: Getting Started

Before you can run SQL queries, follow these simple steps in order. Most connection problems happen because one of these steps was skipped.

Step 1: Make Sure the Database Server Is Running

The database server is a background service that waits for requests from client programs. It may be running:

  • On your local computer
  • On another computer somewhere on the network

Before doing anything else, verify that the server is running and available. If the server is stopped, no client application can connect to it.

Step 2: Start the Database Client

A database client is a program that sends requests to the database server and displays the results.

In this course, our client application is:

  • Visual Studio Code (VS Code)
  • SQL Server extensions installed

Make sure VS Code is installed and running before continuing.

Step 3: Connect the Client to the Server

The client must create a connection to the database server.

Typical Windows Local Setup
  • Host: localhost\SQLEXPRESS
  • Port: 1433
  • Authentication: Windows Authentication
  • Encryption: Optional

If you are using a different operating system or a different server, you will usually use SQL Authentication and provide a username and password.

Successful connection = VS Code can now communicate with the server.

Step 4: Find or Create the Correct Database

A database contains the tables and other objects you will work with. Make sure you are using the correct database before running queries.

  • Use the provided script to create the database and tables when needed.
  • Connect to the master database when creating a new database.
  • Select the course database before running queries.

You can change databases by using:

USE [database_name];

Many tools also allow you to choose the active database from a drop-down menu.

Step 5: Write and Run SQL Queries

Once you are:

  1. Connected to the server
  2. Using the correct database

You can begin writing and executing SQL commands.

  • INSERT data into tables
  • SELECT data from tables
  • UPDATE existing data
  • DELETE data when appropriate

The server processes your request and returns the results to VS Code.

Quick Review
The Basic Sequence
  1. Start the database server.
  2. Open VS Code.
  3. Connect to the server.
  4. Select or create the correct database.
  5. Write and run SQL queries.
