macOS SQL Server Setup Using Docker

SQL Server Express is not available as a native installation on macOS. Instead, Mac users will run SQL Server inside a Docker container and connect to it using Visual Studio Code.

After completing this setup, you will be able to follow the same database exercises as Windows users with only minor connection changes.

Step 1: Install Docker Desktop

  1. Download Docker Desktop for macOS.
  2. Install using the default options.
  3. Launch Docker Desktop.
  4. Wait until Docker reports that it is running.
Key Idea: Docker allows you to run SQL Server inside a Linux container on your Mac.

Step 2: Verify Docker is Running

  1. Open Terminal.
  2. Run the following command:
docker --version

If Docker is installed correctly, a version number should be displayed.

Step 3: Create a SQL Server Container

Run the following command in Terminal:

docker run \
-e "ACCEPT_EULA=Y" \
-e "MSSQL_SA_PASSWORD=Password123!" \
-p 1433:1433 \
--name sqlserver \
-d mcr.microsoft.com/mssql/server:2022-latest

This command downloads SQL Server and creates a container named sqlserver.

Save the SA password. You will need it later when connecting from VS Code.

Step 4: Verify the Container is Running

Run:

docker ps

Verify that a container named sqlserver appears in the list.

The status should show that the container is running.

Step 5: Install Visual Studio Code

  1. Install Visual Studio Code.
  2. Open VS Code.
  3. Open the Extensions panel.
  4. Install the Microsoft SQL Server (mssql) extension.

Step 6: Connect VS Code to SQL Server

  1. Press Ctrl+Shift+P (or Command+Shift+P).
  2. Select MS SQL: Connect.
  3. Use the following values:
  • Server: localhost
  • Port: 1433
  • Authentication: SQL Login
  • User: sa
  • Password: Password123!
Key Idea: VS Code is the client application. The SQL Server container is the database server.

Step 7: Start Working with Databases

Once connected, you can create databases, tables, and run SQL statements exactly as shown in the classroom exercises. 

CREATE DATABASE StudentDB;
GO

Using the Classroom Instructions with a Docker-Based SQL Server

Most of the classroom instructions will work exactly as written. The main difference is the connection information used in Step 3.

Windows Classroom Computers
Server: localhost\SQLEXPRESS
Authentication: Windows Authentication
macOS Docker Installation
Server: localhost
Port: 1433
Authentication: SQL Login
User: sa
Password: Password123!
Good News: After you connect successfully, the remaining steps are the same. Database creation, table creation, CRUD operations, and SQL queries are identical regardless of whether SQL Server is running locally on Windows or inside a Docker container on macOS.
Mapping the Classroom Concepts
  • Database Server Running → Verify the Docker container is running.
  • Launch Client → Open VS Code.
  • Connect Client to Server → Connect to localhost on port 1433.
  • Create or Connect to Database → Use CREATE DATABASE and USE.
  • Create or Identify Tables → Use CREATE TABLE and inspect existing
