SQL Express Fundamentals Lab

These instructions are intended for the student classroom computers, which have SQL Server Express installed.

In this lab, you will use Visual Studio Code as a database client to connect to a SQL Server Express database server, create a database, create a table, and work with data using basic SQL commands.

Server → Client → Connection → Database → Tables → Data

Step 1: Verify the Database Server is Running

Before you can work with data, the database server must be running.

  1. Open Services in Windows.
  2. Locate SQL Server (SQLEXPRESS).
  3. Verify its status is Running.
  4. If it is stopped, start the service.
Key Idea: SQL Express is the database server. It stores and manages the data.

Step 2: Launch the Database Client

  1. Open Visual Studio Code.
  2. Open the Extensions panel.
  3. Install the Microsoft SQL Server (mssql) extension if it is not already installed.
Key Idea: VS Code is the database client. It sends commands to the database server.

Step 3: Connect the Client to the Server

  1. Press Ctrl+Shift+P.
  2. Select MS SQL: Connect.
  3. Connect using:
    • Server: localhost\SQLEXPRESS
    • Authentication: Windows Authentication
Key Idea: A connection allows your client application to communicate with the database server.

Step 4: Create or Connect to a Database

A database is a container that holds tables and other database objects. 

CREATE DATABASE StudentDB;
GO

USE StudentDB;
GO
Key Idea: A server can contain many databases.

Step 5: Create a Table

Tables store data in rows and columns. 

CREATE TABLE Students
(
    StudentID INT PRIMARY KEY,
    FirstName VARCHAR(50),
    Major VARCHAR(50)
);
GO
Key Idea: Tables are where most data is stored.

Step 6: Use CRUD Operations

CRUD stands for:

  • Create - Add data
  • Read - View data
  • Update - Change data
  • Delete - Remove data
Create (INSERT)
INSERT INTO Students
VALUES
    (1, 'Emma', 'Cybersecurity'),
    (2, 'Noah', 'Business'),
    (3, 'Ava', 'Computer Science');
GO
Read (SELECT)
SELECT *
FROM Students;
GO
Update (UPDATE)
UPDATE Students
SET Major = 'Information Systems'
WHERE StudentID = 2;
GO
Delete (DELETE)
DELETE FROM Students
WHERE StudentID = 3;
GO

Learning Objectives

  • Understand the difference between a database server and a client.
  • Connect VS Code to SQL Server Express.
  • Create and use a database.
  • Create a table.
  • Perform basic CRUD operations.
  • Verify results using SQL queries.
