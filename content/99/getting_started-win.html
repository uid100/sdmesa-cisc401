Windows Home Installation Guide

Use these instructions if you are installing SQL Server Express on your own Windows computer rather than using a classroom lab computer.

After completing the installation and configuration steps below, return to the classroom exercise instructions and complete the database activities exactly as written.

Step 1: Install Visual Studio Code

  1. Download Visual Studio Code.
  2. Install using the default settings.
  3. Launch VS Code.
  4. Install the Microsoft SQL Server (mssql) extension.
VS Code will serve as your database client application.

Step 2: Download SQL Server Express

  1. Download SQL Server Express from Microsoft's website.
  2. Run the installer.
  3. Select Basic installation if you are new to SQL Server.
  4. Allow the installation to complete.
SQL Server Express is the database server that will store and manage your data.

Step 3: Verify the SQL Server Service is Running

  1. Press Windows + R.
  2. Type services.msc.
  3. Locate SQL Server (SQLEXPRESS).
  4. Verify the status is Running.
  5. If necessary, start the service.
The database server must be running before VS Code can connect to it.

Step 4: Determine Your Server Name

A default SQL Express installation usually creates the instance: 

localhost\SQLEXPRESS

If you selected different installation options, your instance name may vary.

You will use this server name when connecting from VS Code.

Step 5: Test the Connection from VS Code

  1. Open VS Code.
  2. Press Ctrl + Shift + P.
  3. Select MS SQL: Connect.
  4. Use:
Server: localhost\SQLEXPRESS
Authentication: Windows Authentication

If the connection succeeds, your installation is complete.

Next Step: Use the Classroom Exercise

Once you have successfully connected to your local SQL Server Express instance, return to the classroom exercise instructions.

Do not repeat the installation process. Continue with:

  • Verify the database server is running.
  • Launch the database client (VS Code).
  • Connect the client to the server.
  • Create or connect to a database.
  • Create or identify tables.
  • Perform CRUD operations using SQL.
