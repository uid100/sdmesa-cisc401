Database Basics Checklist

A step-by-step guide to understanding client-server database architecture and making your first connection.

Step 1
The Database Server

The database server runs as a background process providing a service that quietly waits for incoming network requests.

Action: Check that your database server is running. It may be hosted on your local computer or on a remote machine anywhere on the network.
Step 2
The Database Client

The database client application is a software program that you interact with directly. It sends SQL requests to the server and receives data results back to display on your screen.

Action: While there are many client tools available, we will use Visual Studio Code with SQL extensions. Make sure VS Code is installed, configured, and running.
Step 3
Establish Connection & Authentication

Your client needs to form a connection to the server before sending commands. How you authenticate depends on your system setup:

Windows & Local Server
  • Host: localhost\SQLEXPRESS
  • Port: 1433
  • Auth: Windows Authentication
  • Encryption: Set to Optional
Non-Windows / Remote Server

Use SQL Authentication with an explicit Username and Password, as the client and server are not already logged into the same OS account.

Step 4
Find or Create the Database

A database defines the schema (the set of tables, relationships, and rules) you will interact with.

  • Point to the master database first when executing a script to CREATE a brand new database.
  • Once created, switch context to your target database using the SQL command:
    USE [database_name];
    or select it using the database drop-down menu in VS Code.
Step 5
Write & Run Queries

With an active connection established and the correct database selected, you are ready to write and execute your SQL queries to insert, modify, and retrieve data!
